Account questions are the most common forensics archetype, and the one where
the "read before you fix" rule matters most. The account a question asks about
is usually the same account your checklist tells you to delete.

## Reading a passwd entry

```
$ getent passwd backdoor
backdoor:x:1007:1007::/home/backdoor:/bin/bash
```

The fields, in order, separated by colons:

```
name : password : UID : GID : comment : home : shell
```

The `x` in the password field means the actual hash lives in `/etc/shadow`,
which is normal. The third field is the UID and the fourth is the GID — that
position pattern is worth memorising, because questions ask for those numbers
constantly.

For everything about one user at once:

```
id backdoor
```

That prints the UID, the primary GID, and every group the account belongs to.

## Groups

```
$ getent group contractors
contractors:x:1010:desmond,priya
```

Same shape: name, password placeholder, GID, then the member list. The GID is
the third field, exactly like the UID in passwd.

## UID 0 is the one that matters

Linux decides who is root by number, not by name:

```
grep ':0:' /etc/passwd
awk -F: '$3==0 {print $1}' /etc/passwd
```

Either should print `root` and nothing else. An account named `eviladmin` with
UID 0 has complete root privileges no matter how ordinary the name looks. This
is one of the most serious things planted on a competition image, and it is
frequently both a forensics answer and a scored vulnerability at the same time.

That overlap is exactly why you read the questions first. Remove the account to
score the vuln, and the forensics answer disappears with it.

## Finding the humans

```
awk -F: '$3>=1000 && $3<65534 {print $1}' /etc/passwd
```

System accounts sit below UID 1000 and `nobody` sits at 65534, so this leaves
the real people. Compare that list against the README's authorized users — the
account that appears here but not there is usually what a question is about.

## On Windows

```
Get-LocalUser
Get-LocalGroupMember Administrators
wmic useraccount get name,sid
```

Windows identifies accounts by SID rather than UID. A question asking for a
SID wants the whole string, including the long numeric portion — copy it, do
not transcribe it.
