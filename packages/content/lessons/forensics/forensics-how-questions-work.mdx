Forensics questions are the fastest points on a CyberPatriot image. They need
no configuration changes, they can't break the machine, and each one is worth
real points. They are also the easiest points to throw away, in two specific
ways this lesson exists to prevent.

## Read them first. Before anything.

The forensics questions sit on the desktop. Open every one of them before you
touch a single setting.

The reason is not organisation, it is evidence. A forensics question might ask
for the UID of an unauthorized user — the same user your checklist tells you
to delete. Delete first, and the answer is gone. It might ask which port a
suspicious service was listening on, and your hardening pass disables that
service. It might ask for the hash of a file you are about to remove.

Fixing a vulnerability destroys the evidence. Read, answer, then fix.

## Answer exactly what was asked

Every forensics answer is graded by comparing your text against a stored
string. There is no partial credit and no interpretation. If the question
asks for a username, submit `eviladmin`, not `/home/eviladmin` and not the
whole `/etc/passwd` line.

The question states its format, and it states it for a reason. Common shapes:

- **A username** — the name only.
- **A UID or GID** — the number only, no name, no colons.
- **A filename** — sometimes the name alone, sometimes the full path. Read
  which one it asked for.
- **A hash** — the full hex string, nothing else.
- **A port number** — the number, not `tcp/22` and not `:22`.

## The habits that keep the points

Copy and paste rather than retyping. A hash you transcribe by hand will
eventually have a wrong character in it, and you will not spot it.

Trim whitespace. A trailing space or a newline can be the difference between
scoring and not.

Watch the case. Some answers are case-insensitive and some are not; matching
what you actually saw on the machine is always safe.

Answer from the machine, not from memory. If a question asks what is listening
on a port, run the command and read the output. A plausible guess that happens
to be wrong scores exactly the same as no answer at all.

## One more thing worth knowing

You can answer forensics questions at any point in the round, and they don't
expire. But the evidence does. Do them first, while the machine is still in
the state the questions were written against.
